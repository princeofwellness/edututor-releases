# EduTutor.AI — Desktop Release Assets

This repo exists only to host the public download assets for the EduTutor.AI desktop app:

- `EduTutor-Setup-<version>.exe` — Windows installer (small ~500 MB base bundle)
- `ue5-engine-<version>.zip` — 3D MetaHuman avatar engine (~1.5 GB, fetched on first launch)
- `ue5-engine-<version>.zip.sha256` — integrity hash for the avatar engine

The source code, issue tracker, and changelog live in the private development repo
`princeofwellness/edotutor`. This repo is a **distribution mirror** — there is no
code here, only the binaries the app needs to function.

## Install

Go to [the latest release](https://github.com/princeofwellness/edututor-releases/releases/latest)
and download `EduTutor-Setup-<version>.exe`. Run the installer. On first launch the
app downloads `ue5-engine-<version>.zip` automatically from this repo's release page.
